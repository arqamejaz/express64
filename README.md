# Express 64 - Beer & Wine Store Website

Modern, responsive, and SEO-friendly website for Express 64 Beer & Wine store.

## Features

- **Modern Design**: Clean, professional layout with blue and red color scheme
- **Responsive**: Fully optimized for desktop, tablet, and mobile devices
- **SEO Optimized**: Comprehensive meta tags, structured data, and optimized content
- **Animations**: Smooth GSAP animations and interactive elements
- **Performance**: Optimized images and progressive web app features
- **Offline Support**: Service worker for offline functionality

## Sections

1. **Hero Section**: Eye-catching banner with store tagline
2. **About Us**: Information about Express 64 and statistics
3. **Services**: Six main service categories
4. **Why Choose Us**: Five key advantages
5. **Gallery**: Store interior and product showcase
6. **Contact**: Location info, contact form, and details

## Technical Stack

- **HTML5**: Semantic markup with accessibility features
- **CSS3**: Modern styling with Flexbox and Grid
- **JavaScript**: GSAP animations and interactive features
- **PWA**: Service worker for offline functionality
- **SEO**: Structured data and comprehensive meta tags

## Local Development

To run locally:

1. Navigate to the project directory
2. Start a local server: `python3 -m http.server 8080`
3. Open http://localhost:8080 in your browser
